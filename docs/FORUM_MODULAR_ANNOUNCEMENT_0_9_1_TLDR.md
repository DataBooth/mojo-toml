# TL;DR: Mojo 1.0 beta migration complete for 5 libraries (`0.9.1`)

Quick update: I’ve completed Mojo 1.0 beta migration for five DataBooth libraries, all now aligned on **`0.9.1`**:

- `mojo-toml`
- `mojo-ini`
- `mojo-yaml`
- `mojo-dotenv`
- `mojo-asciichart`

For these five libraries, **all earlier versions are now deprecated**.  
If you’re consuming them, please pin to **`==0.9.1`** for now.

I’m aiming to make the final step from Mojo 1.0 beta to Mojo v1.0 a smaller transition than previous upgrades.
